# 📰 News App

A modern and responsive **News Application** built using **React.js** that fetches real-time news using a News API. 🚀

---

## ✨ Features

- 🌍 Top Headlines by Country
- 🏷️ Category-wise News
- ♾️ Infinite Scroll Pagination
- ⚡ Fast & Responsive UI
- 🖼️ News Image Preview
- 📅 Published Date & Author
- 🔗 Read Full Article Button
- 🔄 Live API Data Fetching

---

## 🛠️ Tech Stack

- ⚛️ React.js
- 🎨 Bootstrap
- 🌐 News API
- 📦 React Infinite Scroll Component
